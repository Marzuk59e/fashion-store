# Project Vision: AI Photo Assistant & Social Media Optimizer

## Core Mission
To eliminate friction in social media photo sharing by automating visual enhancements, filter selection, formatting, and caption generation.

## Key Problems & Required Solutions Matrix

1. **Problem: Underexposed / Blurry / Poor Color Lighting**
   - *Solution:* HTML5 Canvas real-time pixel analysis + 1-Click AI Auto-Fix for brightness, contrast, and saturation.

2. **Problem: Filter Overload & Unnatural Edits**
   - *Solution:* Smart preset recommendation based on photo classification (Portrait, Landscape, Sunset, Food, Night).

3. **Problem: Writer's Block for Captions & Hashtags**
   - *Solution:* Context-aware AI caption generator with 4 tone options (Aesthetic, Funny, Professional, Short) + automated hashtag list with copy-to-clipboard.

4. **Problem: Platform Aspect Ratio & Cropping Friction**
   - *Solution:* Preset crop masks for Instagram (4:5, 1:1, 9:16), Facebook, and LinkedIn.

5. **Problem: Privacy & Cost Concerns**
   - *Solution:* Client-side local canvas rendering ($0 cost, 0 lag) + Optional free Gemini API integration for vision/captions.
